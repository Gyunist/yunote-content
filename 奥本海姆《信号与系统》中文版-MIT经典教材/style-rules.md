# Markdown 重建规则

- 先用固定PaddleOCR-VL API完成全书预识别，但无论结果是否正常都必须逐页查看PDF原页。
- PDF原页是正文、公式、结构、编号、图片身份与引用关系的最终权威；JSON与markdown.text只作参考。
- 图片优先采用与原页核对合格的markdown.images，其次outputImages；不合格时才使用匹配原图或PDF裁切图。
- 最终文档第一个非空行是唯一H1书名；章用H2、节用H3、小节用H4，并在H2-H6末尾写唯一 `sec` ID。
- 例题、定义、定理、证明、解答、习题、注释、页眉和印刷目录项不能使用标题，改用粗体、列表或引用。
- 行内公式使用 `$...$`；编号行间公式使用独立开行 `$$` 和闭行 `$${#eq:id}`。
- 不使用 `\(...\)`、`\[...\]`、`\label`、`\ref`、`\eqref` 或 `\tag`。
- 中间图片放入 `Figures/`，章节中写 `../Figures/<唯一文件名>`；合并后只写文件名。
- 图注保留 `$...$` 与明确的交叉引用；正文和图注支持 `sec`、`fig`、`eq`、`tbl` 四类引用。
- 编号表格使用 `Table: 标题 {#tbl:id}`，并紧邻其后的GFM表格。
- 复杂表格无法可靠展平时保存为图片并补充可选择的文字说明。
- 脚注改写为 `〔注 N〕` 和小节末尾的 `**注 N**`，不依赖脚注扩展。
- 未确定的“上图”“下式”等引用记录到 `pending-references.md`，不得猜测。
- 每批只处理完整小节或不超过12页、15000字、6页公式密集页或8页图片/表格密集页。
