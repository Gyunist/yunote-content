## Crepe$123$

The `Crepe` class is the main entry point for creating an editor.

### Constructor

```typescript
new Crepe({
  root: HTMLElement,
  defaultValue?: string,
})
```

### Methods

* `create()` - Initialize the editor

* `destroy()` - Destroy the editor

* `getMarkdown()` - Get current markdown content
